# Changelog

All notable changes to **LX Split-Screen Quick Build**.

## v1.1.0

Update to an already published mod. Earlier versions are on the Workshop page.

### Changed in this version

- All menu labels, group names and tooltips moved to translation files (EN/ES/RU).
- The menu and the available/total counters can be switched off in Options -> MODS.
- Groups are keyed internally, so switching language no longer regroups the catalogue.

### Included

- Build from the context menu
- Everything that matters, grouped
- Tooltips that answer the question
- Same engine as the vanilla window
- Keeps building
